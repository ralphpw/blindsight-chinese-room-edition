# Legal Requirements: Using Watts' Exact Language in Translation

**Legal Question:** Can we use Peter Watts' exact words/phrases from *Blindsight* in our translation?  
**Short Answer:** Yes, with specific limitations and attribution requirements.

**CRITICAL:** These are legal requirements for fair use compliance, not optional guidelines.

---

## Legal Framework

### Fair Use Doctrine (U.S. Copyright Law)

Our translation project qualifies as **transformative fair use** because:
1. **Purpose:** Educational (making dense text accessible) + Commentary (meta-ironic Chinese Room frame)
2. **Nature:** Published novel (favors fair use vs. unpublished work)
3. **Amount:** We're translating the whole work, BUT significantly transforming it
4. **Effect:** Unlikely to harm market (targets readers who already bounced off original)

**Key Point:** Fair use allows us to quote and reference the original extensively because our purpose is transformative, not substitutive.

---

## What We CAN Use Exactly

### 1. Character-Specific Phrases (Sarasti's Voice)

**YES - Use Watts' exact language when:**
- Sarasti's precise, clinical terminology is perfect already
- The exact phrasing IS the character (changing it loses voice)
- Scientific/technical terms Watts coined or used distinctively
- Phrases that are load-bearing for meaning

**Examples:**
- Sarasti's commands: "You have thirty seconds."
- Technical jargon: "synthesist," "Chinese Room," "zombie mode"
- Character-specific vocabulary that defines them
- Philosophical concepts integral to the book

**Why This Is Legal:**
- Small snippets (phrases/sentences) vs. whole paragraphs
- Necessary to preserve character voice (transformative purpose)
- We're not copying for copying's sake - we're using precise language where precision matters

### 2. Scientific/Technical Terminology

**YES - Use Watts' exact terms when:**
- He invented or specifically defined the term
- The scientific concept requires that exact phrasing
- Common scientific language (not copyrightable)

**Examples:**
- "Theseus" (ship name)
- "Scrambler" (alien species)
- "Gang of Four" (character designation)
- Neuroscience terms (solipsism syndrome, hemispheric specialization, etc.)

### 3. Recurring Motifs & Signature Phrases

**YES - Use exact phrases when:**
- They're thematic anchors ("Chinese Room")
- They recur throughout the book (motifs)
- Changing them would break internal consistency

**MUST ATTRIBUTE:** Note in Appendix D that specific recurring phrases are preserved from original for thematic consistency.

---

## What We MUST Change

### 1. Prose Structure & Description

**NO - Cannot copy paragraphs verbatim:**
- Descriptive passages must be rewritten
- Narrative prose must be transformed (that's the whole point)
- Plot events described in our own words (even if inspired by Watts)

**Example:**
- ❌ Copy Watts' description of Rorschach word-for-word
- ✅ Describe Rorschach using similar concepts but different sentence structure

### 2. Extended Dialogue

**NO - Cannot copy entire conversations:**
- Multi-sentence dialogue exchanges must be paraphrased
- Conversation flow can be similar but not identical
- We translate the *meaning* not transcribe the *text*

**Exception:** Short, character-defining lines (see Section 1 above)

---

## The Practical Rule

### "Phrase-Level" vs. "Paragraph-Level"

**PHRASE-LEVEL (OK to use exactly):**
- Individual sentences or shorter
- Character-defining vocabulary
- Technical terms and coined words
- Thematic phrases (Chinese Room, etc.)

**PARAGRAPH-LEVEL (MUST transform):**
- Descriptive passages
- Narrative prose
- Extended dialogue
- Plot summaries

## Guidelines for Translation Tasks

### When Translating Dialogue

**Sarasti's Lines:**
```markdown
ORIGINAL: "You have thirty seconds."
TRANSLATION: "You have thirty seconds." ✅ (Use exactly - defines his efficiency)

ORIGINAL: [Long technical explanation]
TRANSLATION: [Rewrite in Sarasti's style] ✅ (Transform but keep voice)
```

**Other Characters:**
- Short, character-defining lines: Can use exactly
- Longer speeches: Transform structure, preserve voice
- Technical jargon: Use Watts' terms (they're precise)

### When Describing Scenes

**Setting/Atmosphere:**
```markdown
ORIGINAL: [Watts' 3-paragraph Rorschach description]
TRANSLATION: [Our 2-paragraph description using similar concepts, different words] ✅

Key concepts to preserve: Non-Euclidean, organic/mechanical hybrid, unsettling scale
Words/phrases we can reuse: Specific technical terms, ship names, measurements
```

**Action Sequences:**
- Rewrite completely in our voice
- Preserve plot beats and order
- Use different sentence structures
- Maintain Watts' pacing concept

## The "Would a Reader Notice?" Test

**Good rule of thumb:**

If a reader comparing our translation to the original would say:
- ✅ "They captured Sarasti's voice perfectly!" → OK
- ✅ "They used the same technical terms (properly)" → OK
- ✅ "The Chinese Room theme is preserved" → OK
- ❌ "This is just Watts' text with minor edits" → NOT OK
- ❌ "They copied this whole scene word-for-word" → NOT OK

## Special Case: Sarasti's Voice

### Why Sarasti Gets Special Treatment

**Sarasti speaks in ultra-precise, ultra-efficient language.** 

Watts crafted his dialogue to be:
- Minimalist (every word chosen for efficiency)
- Clinical (zero emotional content)
- Precise (scientific/mathematical exactness)

**Translation Problem:** If we "translate" Sarasti's already-minimal speech, we might:
- Add unnecessary words (violates his efficiency)
- Soften his edges (loses predatory quality)
- Lose the precision (meaning changes)

**Solution:** Use Watts' exact phrasing for Sarasti's short directives and commands.

**Legal Justification:**
- Character voice is core to our transformative purpose
- Using different words would HARM our translation quality
- Short phrases (not paragraphs)
- Necessary for artistic/educational purpose

**Example:**
```markdown
WATTS: "You have thirty seconds."
US: "You have thirty seconds." ← Use exactly

WHY: 
- 4 words, ultra-efficient
- No article ("You have the thirty seconds") would be wrong
- No softening ("Please take thirty seconds") would destroy character
- No expansion ("You have thirty seconds to complete this") adds fluff
- This IS Sarasti - changing it loses him
```

## When in Doubt

**Ask these questions:**

1. **Is it necessary for character voice?** (Especially Sarasti) → OK to use exactly
2. **Is it a technical term or coined word?** → OK to use exactly
3. **Is it a recurring thematic phrase?** → OK to use exactly
4. **Is it longer than a sentence or two?** → MUST transform
5. **Is it descriptive prose?** → MUST transform
6. **Would changing it harm our translation quality?** → OK to preserve

**If still unsure:** Err on side of transformation, but note in comments where Watts' exact phrasing would be superior.
