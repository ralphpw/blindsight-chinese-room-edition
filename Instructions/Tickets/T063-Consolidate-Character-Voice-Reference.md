## Objective

Fill in the `Instructions/Character-Voice-Reference.md` template with consolidated information from all character studies (T003-T007), creating a single reference document that translators can read before each chapter to refresh all character voices at once.

---

## Process

### Phase 1: Extract Human Character Profiles (30 minutes)

For each character study (T003-T007):

1. **Read the full character study**
2. **Extract these key elements:**
   - Voice profile (3-4 bullet points)
   - Speech patterns (specific examples)
   - Key vocabulary/jargon
   - Translation rules
3. **Condense to quick-reference format**
   - Focus on actionable guidance
   - Include 2-3 specific examples
   - Keep each character section to ~1 page

### Phase 2: Add Non-Human Characters (20 minutes)

4. **Analyze Scramblers**
   - Read all Scrambler scenes from novel
   - Document their "speech" patterns
   - Note uncanny/disturbing qualities
   - Create translation rules

5. **Analyze Rorschach**
   - Read description passages
   - Note disorienting language
   - Document non-Euclidean description style
   - Create translation rules

6. **Analyze Theseus (Ship AI)**
   - Read all ship communication
   - Note flat/functional style
   - Document lack of personality
   - Create translation rules

### Phase 3: Character Dynamics (10 minutes)

7. **Document Interaction Patterns**
   - How does each pairing interact?
   - Power dynamics (especially Sarasti)
   - Keeton's relationships with each
   - Translation implications

### Phase 4: Quick Reference Tools (15 minutes)

8. **Create Checklists**
   - Voice consistency checklist
   - "Who says what" quick reference
   - Translation priority guide
   - Common pitfalls per character

9. **Add Cross-References**
   - Link back to individual studies
   - Note where deeper analysis needed
   - Provide chapter references

## Quality Standards

**Actionable Guidance:**
- Not: "Sarasti is cold"
- But: "Sarasti uses short declarative sentences, never explains decisions, questions are tests not requests. Example: 'You have thirty seconds' not 'I need you to hurry because...'"

**Quick Reference:**
- Each character section fits on ~1 page
- Key points in bullet format
- Examples are specific and memorable
- Can scan document in 20 minutes before translation

**Completeness:**
- Every character who speaks gets a section
- Non-human "voices" included
- Interaction patterns documented
- Translation implications explicit
