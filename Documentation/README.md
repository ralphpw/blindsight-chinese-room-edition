## Key Principles

### Respecting Watts
- Original author is Peter Watts—we're translating for accessibility
- All concepts, plot, and world-building are his
- Frame as "alternative translation" not "correction"
- Generous attribution on every page

### Transparency
- System prompts published (Appendix in final work)
- Methodology documented
- Process open-sourced (GitHub)
- Reproducibility encouraged

### Accessibility
- Primary goal: Help bounced readers access Watts' brilliant ideas
- Secondary goal: Educational resource for SF literature/AI ethics courses
- Tertiary goal: Demonstrate responsible AI creative use

### Philosophical Purity
- Single-pass translation (one Chinese Room, like Sarasti)
- Claude 3.5 Sonnet (primary translator)
- Human edits only for scientific accuracy and typos
- Accept rough edges (v0.5 Beta intentionally raw)
